A — Modale / Fenêtre popup

Un bouton dans le chatter ouvre une fenêtre modale avec l'historique complet. Le chatter normal reste intact.

Avantages

  • Chatter non modifié
  • Plein écran possible
  • Simple à implémenter

Inconvénients

  • Interruption du contexte
  • Pas de navigation directe

B — Onglets dans le chatter

Deux onglets : "Discussion" (chatter normal) et "Historique partenaire" (tous les échanges triés). Cohabitent côte à côte.

Avantages

  • Pas de popup
  • Navigation fluide
  • Natif Odoo 18

Inconvénients

  • Plus complexe JS
  • Chatter JS à surcharger

C — Section dépliable en bas du chatter

Une section "Historique partenaire" s'affiche sous le chatter normal et se déplie à la demande. Les deux contenus coexistent.

Avantages

  • Très visible
  • Pas de popup
  • Contexte préservé

Inconvénients

  • Allonge la page
  • Mélange visuel possible

D — Vue dédiée (action séparée)

Un bouton "smart button" sur la fiche partenaire ouvre une vue liste dédiée (comme les commandes, factures, etc.) avec filtres et recherche.

Avantages

  • Pattern Odoo natif
  • Filtres/recherche faciles
  • Plus scalable

Inconvénients

  • Quitte la fiche
  • Pas dans le chatter
  • Moins contextualisé

Cliquez sur une ou plusieurs options, puis répondez dans le terminal.

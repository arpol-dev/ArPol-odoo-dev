Features

1A convenient way to view images on your site

2Get a preview window for the images in the following blocks

3In the block, you can choose whether to open the image viewing window

4Opening multiple images in a block

Documentation

Installation

  • Install module us_website_image_zoom
  • Please note, the module depends on the website module, otherwise it will be installed automatically

Configuration

  • Go to the website module and switch to edit mode
  • Select one of the blocks for which the "Image Zoom" option is available
  • In the "Customize" section for the block, the "Image Zoom" option will appear
  • Please note that by default the image opening is not set, to enable this option, select the "Pop-up on Click" item in the "Image Zoom" field
  • The image magnification option is set separately for each block

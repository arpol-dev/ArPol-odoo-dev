# README for website_sale_product_minimal_price_with_tax

This Odoo module extends the functionality of the existing `website_sale_product_minimal_price` module by adding tax information to the pricing details of products. It inherits the method `get_combination_info_pricelist_atributes` and modifies it to include tax calculations in the response.

## Features

- Inherits from the `website_sale_product_minimal_price` module.
- Extends the `get_combination_info_pricelist_atributes` method to include tax information.
- Provides a seamless integration with existing Odoo e-commerce functionalities.

## Installation

1. Clone the repository or download the module files.
2. Place the `website_sale_product_minimal_price_with_tax` directory into your Odoo addons directory.
3. Update the app list in Odoo.
4. Install the module from the Odoo apps interface.

## Usage

Once installed, the module will automatically enhance the product pricing information displayed on the website by including applicable tax details. This will help customers see the total cost including taxes when viewing product combinations.

## Compatibility

This module is compatible with Odoo versions that support the `website_sale_product_minimal_price` module.
